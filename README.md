# Bot-books
Creación de un bot desde telegram, bajo la integración de una API en node.js para la inserción de registro de libros en Notion


##  Tecnologías
- Node.js
- Express
- Notion API
- Telegram Bot API

##  Instalación

```bash
npm install
```

##  Deploy en AWS

Actualmente se contempló la implementeación de desplegue en AWS EC2 usando:
- PM2 (para ejecución 24/7)
- Variables de entorno (.env)

El bot funciona de forma continua sin necesidad de servidor local.
